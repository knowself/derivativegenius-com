## 1. Executive Summary & The Tri-Product Asymmetric Flywheel

Derivative Genius is an AI-native product studio and high-margin agency platform. Rather than building isolated tools or competing in low-margin generic services, our commercial strategy couples three complementary codebases into an **integrated value ladder and asymmetric distribution flywheel**:

```
+---------------------------------------------------------------------------------------------------+
|                                 THE ASYMMETRIC COMMERCIAL FLYWHEEL                                |
+---------------------------------------------------------------------------------------------------+
|                                                                                                   |
|   1. INGESTION & DATA REFINERY           2. VISUAL SYNTHESIS               3. REVENUE ENGINE      |
|     [ Apify.com Actors ]                    [ Removie MCP ]                 [ /centurion & GDG ]  |
|               |                                    |                                |             |
|   - Low-cost web scrapers              - Governed Remotion engine          - High-ticket agency   |
|   - Google Maps, Indeed, Permits       - 4 templates (Briefing, Social)    - VSL Sprints ($2.5k)  |
|   - $0.05–$0.15 / account cost         - 16:9, 9:16, 1:1 render API        - Retainers ($500–$750)|
|               |                                    |                                |             |
|               +-----------------> [ GDG REFINERY ] <--------------------------------+             |
|                               (5-Stage Trust Pipeline)                                            |
|                                    COLLECT -> REFINE                                              |
|                                    REASON -> LOCALIZE                                             |
|                                         DELIVER                                                   |
|                                            |                                                      |
|                       Delivers verifiable buying signals &                                        |
|                       programmatic VSLs directly into agency hands                                |
+---------------------------------------------------------------------------------------------------+
```

### The Three Pillars:
1. **Derivative Genius Web & Operator Core ([`dg-web`](file:///home/knowself/dev/dg-web/)):**
   - Flagship agency offering "smart digital employees" (custom AI web applications, booking flows, semantic search).
   - Core offers: **Single-Problem VSL Sprints** ($1,500–$2,500 fixed, 10-day turnaround), **Core Retainers** ($300/mo), and **Growth Retainers** ($500/mo + ad spend).
   - System of Record: [`/centurion`](file:///home/knowself/dev/dg-web/src/app/centurion/) operator portal for pipeline, compliance, lead scoring, and manual outreach tracking.
2. **Global Decision Grid ([`globaldecisiongrid`](file:///home/knowself/dev/globaldecisiongrid/)):**
   - An institutional multi-tenant decision intelligence refinery powered by a 13-table Neon Postgres schema with cryptographic trust envelopes.
   - Beachhead Vertical: **Local Opportunity Radar** (monitoring hiring growth + operational leaks, mobile viewport failures, review latency).
   - Monetization: **Founding Partner Sprints** ($499 one-time), **Agency Retainers** ($750/mo), and **Managed Pilots** ($1,500 upfront).
3. **Removie Programmable Video Engine ([`removiemcp`](file:///home/knowself/dev/removiemcp/)):**
   - "One governed video engine, many trusted interfaces" built on Next.js 16, React 19, Remotion 4.0, and the official MCP SDK.
   - Converts raw market signals and VSL scripts into broadcast-grade video via 4 interfaces (Web Studio, MCP Server, HTTP API `/v1/*`, and CLI).
   - Replaces manual video production for DG's VSL Sprints and generates automated, personalized video decision briefings for GDG agency subscribers.
4. **The Apify.com Move:**
   - Moves data acquisition away from brittle custom scrapers to containerized, cloud-hosted Apify Actors (Google Maps, Indeed jobs, local business registers) costing pennies per thousand records ($0.50/1k records).
   - Feeds Stage 1 (`COLLECT`) of the GDG refinery, enabling continuous, multi-city market surveillance without operational engineering friction.

### 3.2 Move into Apify.com (`apify.com` Actor Ingestion Fabric)

#### Strategic Justification:
- **The Ephemerality of Scrapers:** Building and maintaining private scrapers for Google Maps, Yelp, and job boards results in high maintenance overhead due to DOM changes and IP blocking.
- **The Asymmetric API Arbitrage:** Apify provides battle-tested actors (e.g., `compass/crawler-google-places`, Indeed Job Scraper) running on distributed residential proxies for ~$0.50 to $1.00 per 1,000 records.
- Wrapping raw Apify extractions into the GDG **5-Stage Refinery** adds a 50x–100x value multiplier: raw scrapers sell for $35/mo; verifiable buying triggers with trust envelopes sell for $499–$750/mo.

Create scheduled tasks targeting: **Google Maps commercial profiles** and **Indeed HVAC/trade hiring postings** in Lake, Mendocino, and Sonoma counties.<br>4. ## 5. Risk Matrix & Strategic Guardrails

| :--- | :--- | :--- | :--- |
| **Premature Platform Sprawl** | High | High | Enforce strict rule: **No Vertical #2 until Beachhead reaches 10 retainers ($7,500 MRR).** Keep no more than 2 development targets `In progress` simultaneously. |

| **Technology Stack Drift** | Low | Critical | **Strict Stack Policy:** Node.js + Next.js 16 + Neon Postgres + Drizzle ORM only. Absolute permanent ban on Python, Django, Celery, ICP canisters, and caffeine.ai. |
